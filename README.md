# ktav-fonts

## Overview

ktav は、OSS のライセンスのフォントを集めたカタログを持ち、そのフォントを Golem や Aleph のプロジェクトに取り込むソフトウェアである。
取り込むときは、フォントのファイルと一緒にライセンスの文書も置く。
また、使うフォントの組みと出力の種類（PDF、HTML、EPUB）から、成果物に課される義務を示す。
Adobe Fonts の OSS 版にあたるものを目指している。

ktav はまだ何も実装していない。
計画は [docs/roadmap.md](./docs/roadmap.md) に、ここまでの経緯と調査は [docs/research/](./docs/research/) にある。
名前の ktav はヘブライ語で「書体」を表す語で、発音は [ˈktav] である。
リポジトリと公開するライブラリの名前は ktav-fonts とし、それ以外では ktav と呼ぶ。
